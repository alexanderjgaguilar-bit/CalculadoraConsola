## Descripción del Proyecto
Este proyecto consiste en una aplicación de consola desarrollada en C# (.NET Framework) que solicita dos números reales y una clave de operación. Cuenta con un ciclo de repetición controlado por el usuario y un sistema robusto de validación de datos mediante bloques `try-catch` para evitar errores de formato, campos vacíos o divisiones entre cero.
